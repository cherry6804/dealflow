# Infrastructure

This directory is reserved for infrastructure-as-code. No cloud resources,
accounts or credentials are defined here yet.

Environments, required configuration and external provider dependencies are
documented in:

- `docs/product/release-1/E01-environment-and-provider-matrix.md`
- `docs/adr/0030-environment-and-configuration-standards.md`
- `docs/development/engineering-baseline.md`

Staging and production are not provisioned. Adding infrastructure code requires
an approved decision recorded as an ADR.
